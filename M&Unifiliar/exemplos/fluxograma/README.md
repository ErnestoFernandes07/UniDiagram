# Exemplo de pacote — Fluxograma

Modelo API 1 com Processo e Decisão, quatro terminais por componente, apoio superior e categorias Fluxo, Sim e Não. As portas seguem a ordem superior, direita, inferior, esquerda.

Copie esta pasta para `pacotes/fluxograma`, valide `pacote.json` e reinicie o aplicativo. Marque Fluxograma em Bibliotecas +, ou `python app.py --pacote exemplo.fluxograma`.

Este exemplo demonstra que a fundação funciona sem componentes elétricos. Use-o como ponto de partida, alterando ID, nome, componentes e metadados de autoria/licença conforme seu fork. Consulte `docs/CRIAR_PACOTE.md` para o contrato completo.
